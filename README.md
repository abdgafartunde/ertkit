**Resistivity imaging for groundwater exploration, with an honest account of
what the data can resolve.**

ertkit is a Python package for inverting vertical electrical sounding (VES)
data, with 2.5-D electrical resistivity tomography (ERT) to follow. Each
result comes with what is needed to judge it:

- a data error model, and a fit to the noise level rather than to every digit
  of the data;
- sensitivity and depth of investigation, so that unresolved parts of a model
  are marked as such;
- parameter uncertainty and, from release 0.2, the range of equivalent models
  that fit the data equally well.

## Why another resistivity code?

Boreholes are often sited from resistivity models whose reliability was never
quantified. Open tools such as [pyGIMLi](https://www.pygimli.org),
[SimPEG](https://simpeg.xyz) and [ResIPy](https://gitlab.com/hkex/resipy)
already provide excellent modeling and inversion. ertkit focuses on three
things: making reliability the default output, publishing a verification
report with every release, and keeping the code small enough to teach from.
The [design document](https://abdgafartunde.github.io/ertkit/dev/design.html)
gives the full statement of need, the mathematics and the verification plan.

## Quick start

```python
import numpy as np
import ertkit
from ertkit import ves

truth = ves.LayeredModel(resistivity=[150.0, 30.0, 800.0], thickness=[2.0, 15.0])
survey = ves.Survey.schlumberger(ab2=np.geomspace(2.5, 200.0, 22), mn2=0.5)
data = ves.Sounding.synthetic(truth, survey, ertkit.ErrorModel(relative=0.03), rng=5)
# Field data: data = ves.read_csv("sounding.csv")

fit = ves.invert_few_layer(data, n_layers=3, rng=0)
print(fit.model.resistivity, fit.factor)  # values and multiplicative uncertainties
print(fit.depths, fit.depth_std)  # interface depths (m) and their standard deviations
print(ves.invert_smooth(data).doi)  # depth of investigation (m)
```

## Status

Release 0.1 covers vertical electrical sounding: a layered-earth forward
model, few-layer inversion with linearized uncertainty, smooth inversion with
sensitivity and a depth of investigation, CSV input and plotting. Planned
releases:

| Release | Content |
|---|---|
| 0.1 | VES: layered-earth forward model, few-layer and smooth inversion, linearized uncertainty, sensitivity and depth of investigation |
| 0.2 | VES equivalence analysis |
| 0.3 | 2.5-D ERT forward modeling |
| 0.4 | ERT inversion with an error model and cumulative sensitivity |
| 0.5 | ERT depth of investigation and uncertainty maps |
| 0.6 | Field data formats and an end-to-end field example |
| 1.0 | Stable public API |

## Contributing

Bug reports, questions and suggestions are welcome on the
[issue tracker](https://github.com/abdgafartunde/ertkit/issues). To work on
the code, install [uv](https://docs.astral.sh/uv/) and run:

```bash
git clone https://github.com/abdgafartunde/ertkit.git
cd ertkit
uv sync
uv run pytest
```

See the [contributing guide](https://github.com/abdgafartunde/ertkit/blob/main/CONTRIBUTING.md)
