# Verification report

Every accuracy claim in this documentation rests on a check in the test
suite. Each check compares a computed quantity with an exact solution, an
independent method or a statistical expectation, against a tolerance whose
reason is stated; a check passes when the measured value is at most the
tolerance. This table is generated by running those tests for each build of
the documentation; nothing in it is typed by hand.

```{verification-report}
```

The checks follow the acceptance criteria in section 3.5 of the
[design document](dev/design.md). The comparison with pyGIMLi and SimPEG
(item 9) needs those packages and runs in a separate
[weekly workflow](https://github.com/abdgafartunde/ertkit/actions/workflows/weekly.yml),
so it is not in this table. To run the checks yourself:

```bash
uv run pytest -m verification --verification-report=verification.json
```
