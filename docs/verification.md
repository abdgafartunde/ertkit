# Verification report

Every numerical claim in this documentation rests on a check in the test
suite. Each check compares a computed quantity with an exact solution, an
independent method or a statistical expectation, against a tolerance whose
reason is stated. This table is generated by running those tests for each
build of the documentation; nothing in it is typed by hand.

```{verification-report}
```

The checks follow the acceptance criteria in section 3.5 of the
[design document](dev/design.md). To run them yourself:

```bash
uv run pytest -m verification --verification-report=verification.json
```
