# Citing ertkit

Each release of ertkit is archived on Zenodo, which issues a DOI for every
version and a concept DOI that always resolves to the latest version:

- all versions (concept DOI):
  [10.5281/zenodo.23385097](https://doi.org/10.5281/zenodo.23385097)
- version 0.1.0:
  [10.5281/zenodo.23385098](https://doi.org/10.5281/zenodo.23385098)

To make results reproducible, cite the version you used. The citation
metadata are in
[CITATION.cff](https://github.com/abdgafartunde/ertkit/blob/main/CITATION.cff),
from which GitHub offers APA and BibTeX entries ("Cite this repository").

Please also cite the methods ertkit implements; the references are listed in
the [user guide](user_guide/ves.md#references).
