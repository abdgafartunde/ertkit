All notable changes to ertkit are recorded here. The format follows
[Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/), and the
project uses [semantic versioning](https://semver.org/).

## [0.1.0] - 2026-10-15

### Added

- Project foundation (milestone 0.0): packaging with versions from git tags,
  continuous integration on Linux, Windows and macOS, a documentation website,
  a release pipeline using trusted publishing, and contributor guidelines.
- Design document with the mathematics, the verification plan and the
  engineering standards (`docs/dev/design.md`).
- `ertkit.show_versions()` for bug reports.
- VES forward model: `ves.LayeredModel`, `ves.Survey` (Schlumberger soundings
  with finite and changing MN, and Wenner soundings), `ves.forward`,
  `ves.potential`, and the building blocks `ves.resistivity_transform` and
  `ves.hankel_j0` (Guptasarma and Singh 120-point filter).
- `ErrorModel`: measurement errors on the transfer resistance, with a 3%
  relative default that includes a modeling-error floor, and a warning when
  the relative part looks like a percentage (above 0.5).
- `ves.Sounding` (data with their error model; readings with R <= 0 or below
  the noise level are removed with a `DataWarning` that lists their AB/2),
  synthetic data with `Sounding.synthetic`, and CSV input and output with
  `ves.read_csv` and `ves.write_csv` (explicit text encoding; empty
  spreadsheet rows are skipped, and errors give the line and, for a file in
  another encoding, how to read it).
- Warning categories `ConvergenceWarning` and `DataWarning`.
- Few-layer VES inversion, `ves.invert_few_layer`: log parameters, a
  trust-region least-squares search from several starting models within
  resolvable bounds, complex-step Jacobian, linearized uncertainty
  (standard deviations, multiplicative factors, correlations, depths with
  standard deviations), a goodness-of-fit p-value, and optional static-shift
  factors per MN segment (`LayerFit.segment_mn2` maps them to MN/2). Each
  start runs briefly and the best are continued until one converges, which
  makes over-parameterized fits several times faster; a misfit that stays put
  while the parameters drift along a ridge of equivalent models counts as
  converged. Warnings: a poor fit (with a static-shift hint when there are
  several MN segments, and a note that the uncertainties are then too small),
  a fit closer than the errors imply, parameters at their search bounds (with
  advice for each), and poorly determined parameters (uncertainty factor above
  10). The fit with the smallest misfit over all starts is kept, and the
  linearized covariance comes from the singular values of the weighted
  Jacobian, so undetermined parameters get infinite uncertainty. Results are
  `ves.LayerFit` objects, with read-only arrays.
- Smooth (Occam) VES inversion, `ves.invert_smooth`: many layers with
  logarithmically growing thicknesses, the target misfit chi2 = N_d with the
  largest regularization weight that reaches it, the error-weighted
  sensitivity of each layer, and the Oldenburg and Li depth of investigation
  from two reference-model inversions that aim at the same misfit (the top of
  the unresolved zone that reaches the bottom of the model, bridging resolved
  gaps narrower than a factor of 2 in depth, so that it is stable against
  overshoot of the reference models and against the number of layers). When
  chi2 = N_d cannot be reached, the
  model fits 1.1 times the smallest misfit instead, with a warning only if
  that misfit is improbably large. Results are `ves.SmoothFit` objects.
- Every result has normalized `residuals` and a readable `summary()`
  (`ertkit.results.InversionResult`).
- Plotting with matplotlib (`ertkit.plot.sounding`, `ertkit.plot.layered_model`;
  install with `pip install "ertkit[plot]"`). Wenner fits are drawn as one
  curve, and unbounded error bars are cut at the edges of the plot.
- Documentation: a user guide for VES (including error-model guidance and
  choosing the number of layers), six worked examples (few-layer inversion,
  smooth inversion and depth of investigation, equivalence of a suppressed
  layer, static shifts, reading CSV files, checking an installation), and a
  verification report generated by the tests for every documentation build.
- A weekly cross-check of the VES forward model against pyGIMLi and SimPEG
  (with a different Hankel filter), also run before each release.
- An honest-uncertainty test: over 1000 noise draws, the misfit and the
  coverage of the linearized intervals match their theoretical values.
- `arrays.geometric_factor` for any four-electrode array, including remote
  electrodes.
- Verification tests against the two-layer image series (contrasts from
  1e-4 to 1e4) and the Lipschitz integral, and of the depth of investigation
  against a detectable depth computed independently from the true model,
  recorded in a verification report (`pytest -m verification
  --verification-report=PATH`).
